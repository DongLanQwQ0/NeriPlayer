NeriPlayer 适配版标识（2026-10-23）
================================

应用显示名称统一为 NeriPlayer，不附加 vivo。
图标采用用户选定的橙色折叠三角丝带，背景为高亮度、低饱和度的浅暖橙 #FFF1E1。
背景由 Android 资源背景层提供，前景画稿及中央三角开口保留透明通道，
不重新生成或改动用户已选定的丝带造型。原始前景：tools_pub/branding/vivo-orange.png。

运行 python tools_pub/branding/export_vivo_icon.py（依赖 Pillow），生成
app/src/vivoRelease/res/drawable-nodpi/vivo_brand_art.png。
导出保留 RGBA，尺寸 432×432（78,833 字节），1254×1254 原图不进入 APK。
自适应图标背景层为 #FFF1E1（HSV 色相 32°、饱和度约 11.8%、亮度 100%）；
主体相对上一版缩小为 80% 并保持居中，四侧留白为 20.3704%（108dp 中的 22dp）。
图标画布、背景和 432×432 前景资源尺寸均保持不变，只通过前景容器内缩调整主体，
单色图标同步缩放。额外留白用于容纳圆形、圆角和其他系统遮罩的裁剪。
系统主题附加的外框由用户主题控制。

通知小图标单独使用透明背景与透明三角开口的丝带轮廓，不套桌面浅橙底层。
vivoRelease 的 drawable-nodpi/ic_notification_small.xml 复用 vivo_brand_monochrome。
vivo 通知发送透明 ARGB 位图 Icon；原子岛卡片内部的应用图标仍保持原有浅色圆底。
OriginOS 在通知封面角标和状态栏仍可能改取 ApplicationInfo.icon；单独更换 smallIcon
已在真机确认不能改变该取图路径。正式变体因此分开声明：应用系统图标为白底平面丝带，
MainActivity 的启动图标显式保留原有浅橙自适应图标，桌面图标不随通知角标变白。

关于区域保留 NeriPlayer / GPLv3 原文，追加“适配版作者：DongLan”。
仅 vivoRelease 资源覆盖生效；独立包名 moe.ouom.neriplayer.vivo 与固定签名保持不变，
以便覆盖升级并保留数据。原版、debug、上游作者版权、许可证和 GitHub 入口不变。
本次不重新发布已撤回的 vivo-release-421509148。

图稿来源：内置 image_gen。用户先选定 A 并改为橙色，再要求移除背景；
移除背景要求保留橙金色、丝带折叠结构、光影和留白，不添加图形或文字。

资源回归检查：python -B -m unittest discover -s tools_pub/branding -v
覆盖源图与导出图透明通道、中央开口、浅橙背景色与亮度/饱和度，以及三个语言资源
的准确名称与署名。
